# 🐱 貓咪大戰爭 通關紀錄本（跨平台手機／電腦 PWA 版）

一款專為《貓咪大戰爭》玩家設計的**純靜態離線通關紀錄與圖鑑工具**，打開網址即可在 **iPhone、Android、Windows、Mac** 直接使用，並支援「加入主畫面」以獨立 App 模式全螢幕開啟。

## ✨ 主要功能
- **台日雙區合併資料**：支援繁體中文／日文介面即時切換，以及中／日文／編號跨語言搜尋，可獨立檢視台服獨有與日服獨有貓咪。
- **完整關卡與敵人資訊**：內建各冠數倍率切換、遠距離／全方位實際傷害範圍、反向查詢敵人出現關卡。
- **5×2 十格隊伍紀錄**：自動偵測貓咪聯組、記錄砲台／道具／標籤／心得／截圖，支援「已通關／未通關」與「⭐ 珍藏紀錄」。
- **雙帳號獨立貓棚**：分別管理台服與日服帳號的貓咪等級、加值與本能，體力／攻擊依實機成長曲線即時計算。
- **100% 本機離線儲存 ＋ 一鍵備份還原**：所有個人通關紀錄與貓棚皆存於使用者自己的瀏覽器本機資料庫（IndexedDB），可隨時匯出／匯入 `.json` 備份檔跨裝置轉移。

## 🚀 部署到 GitHub Pages 步驟
1. 在 GitHub 建立一個新的公開 Repository，將本專案（含 `docs/` 資料夾）上傳。
   > `.gitignore` 已自動排除 `tools/` 與本機預覽工具，只會上傳 `docs/` 純靜態網站與 `README.md`。
2. 到 GitHub Repository 的 **Settings → Pages**。
3. **Build and deployment → Source** 選擇 **Deploy from a branch**。
4. Branch 選擇 `main`，資料夾選擇 **`/docs`**，按 **Save**。
5. 等待約 1 分鐘，即可透過 `https://<你的帳號>.github.io/<倉庫名稱>/` 直接使用！

## 📱 在手機上當成 App 安裝
- **iPhone（Safari）**：打開網址 → 點底部「分享」按鈕 → 選擇「**加入主畫面**」。
- **Android（Chrome / Edge）**：打開網址 → 點右上角選單（或網址列提示）→ 選擇「**安裝應用程式**／**加到主畫面**」。
